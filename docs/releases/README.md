생성 및 검증 도구는 `.memory/validation/2026-10-29-release-overview/`에 있습니다. 생성기는 현재 `0.01v` 전용이므로 다음 릴리스에서 기존 자료를 덮어쓰는 용도로 사용하지 않습니다. 최신 승인 원본을 반영하려면 새 버전으로 복사해 수정합니다.
