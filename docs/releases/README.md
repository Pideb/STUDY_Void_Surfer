HTML은 이미지 49개와 확정된 사이렌을 파일 안에 포함합니다. 다른 사람에게는 HTML 파일 하나만 전달하면 됩니다. 인터넷 없이도 본문·이미지·지역 선택·피드백 검색·기본 속도 그림을 볼 수 있습니다. 웹폰트, Chart.js의 상세 차트와 PNG 내보내기는 외부 CDN을 사용하며, 인쇄/PDF는 브라우저 기능입니다.

다음 변경도 사용자가 정한 버전으로 새 파일을 만들고 기존 자료는 보존합니다. `versions.json`의 `releases`에 날짜·소스 커밋·문서·검증 결과·배포 여부를 추가하고 `currentVersion`을 갱신합니다. 추가/변경/수정 내용과 실플레이 피드백, 배포 주소도 함께 기록합니다.

이 표기는 사용자가 정한 게임 작업·공유 자료의 버전입니다. npm의 기존 `0.1.0`, Git 태그, 실제 배포 상태는 별도로 관리합니다. 0.01-b에는 일반↔보스 반복, WARNING 설계 보관, 첫 메뉴 소리 활성화, 메뉴 기체 움직임 안정화가 포함됩니다. 데이터베이스와 배포 설정은 이번에 바꾸지 않았습니다.

0.01-b 생성·검증·실제 브라우저 증거는 `.memory/validation/2026-10-29-001b-boss-menu/`에 있습니다. 이전 `.memory/validation/2026-10-29-release-overview/` 생성기는 0.01v 전용이므로 다시 실행해 과거 자료를 덮어쓰지 않습니다. 0.01v 파일은 바이트 단위로 보존했습니다.
