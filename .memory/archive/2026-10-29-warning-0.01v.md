# Dormant WARNING Design — 0.01v

- Archived:2026-10-29 when preparing0.01-b.
- Last deployed source before this change: `f1210bf87e5e789c68c13d3b12a99a6708b4461d`.
- This is preserved design/history, not a currently reachable game mode. The user explicitly intends a later redesigned revival; no revival rules have been chosen.

## Former standalone encounter

- Normal → WARNING → normal → BOSS, repeating.
- First WARNING threshold20; completion chose another threshold5–8 points beyond the current score.
- WARNING wave5 walls with at least2 special barriers, special chance50%, spawn interval1.4s (VELOCITY halves it).
- Base opening180px narrowed to135px. Special success band uses speed×.15s, compared with normal.30s. Moving opening cycle3.2s versus normal4.8s; first-clear unlock required.
- Standalone WARNING wall passes awarded points; boss wall passes did not. Boss wave7/min3 specials, actual boss HP/weapon/pattern behavior was separate.
- Red stage atmosphere, brief central WARNING banner and warning sound; boss used blackout/three-pulse entry/BOSS banner and its own background/music. After two bosses, ambient line lasers could also run during WARNING.
