# 투사체 외곽선

- 사용자 요청대로 투사체 그림의 실제 실루엣을 따라 스테이지 projectile 팔레트의 밝은 색 테두리를 추가한다. 사각 박스·타기팅 원을 추가하지 않는다.
- 원본 이미지·표시 크기36/부모탄62·피격 박스·궤도·속도·해금 조건은 유지한다. 일반/고유 탄막·반환탄의 공통 렌더 경로에 적용한다.
- 실루엣 마스크·밝은 테두리와 얇은 어두운 분리선은 작은 canvas에 최초 한 번 생성하고 이미지/지역/크기별 캐시한다. 매 프레임 blur/filter/픽셀 읽기·큰 원본 이미지 분석을 하지 않는다.
- 6지역 실제 렌더링 전후를 비교하고 모바일·FHD 밀도에서도 가시성을 확인한다. 변경은 커밋하되 push·배포하지 않는다.
