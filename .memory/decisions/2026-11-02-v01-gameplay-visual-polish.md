- Date: 2026-11-02
- Status: confirmed. 사용자 최종 승인: “좋다. 이대로 확정하고 다음 진행하자.”
- Target: 다음 배포 후보 0.1. 현재 실제 배포 0.01-b는 변경하지 않는다.
- 범위: 2026-10-30~11-02 개선 인터뷰 D01~D43의 통합. [원 조사](../research/2026-10-30-v01-improvements-audit.md)는 이력이며 충돌 시 이 문서의 최종 결정을 우선한다.

## 1. 움직이는 벽: 처음부터 움직이고 접근 시 정지
- 화면 진입 시 이미 구멍이 움직여야 한다. 생성 시점과 첫 갱신 사이 도약, 경계 clamp로 오래 평평해지는 문제를 제거한다.
- 벽 앞면과 플레이어 피격 상자의 앞면 사이 160 논리 px에서 수직 움직임이 완전히 멈춘다. 960×540, player x240/halfWidth8 기준 wall x408. 통과 후에도 재개하지 않으며 가로 이동은 계속한다.
- 접근하면서 부드럽게 감속한다. 시안의 마지막40px 감속은 구현 초안이며 사용자 지정 수치로 주장하지 않는다. 이 구간에서의 불연속/고속 큰 dt를 검증한다.
- 이동벽 폭72, 일반 이동벽 후보 비율50%, 첫 보스 클리어 해금 등 기존 규칙 보존.

## 3. WASD 입력·시간·복귀
- 제한시간 첫 보스4초, 두 번째 이후2.5초.
- 키 개수는 현재 곡선 유지: 1차4 / 2차4~5 / 3차4~6 / 4차5~7 / 5차부터6~8. 동일 키4연속 금지.
- 잘못된 유효 WASD는 띠 소리+지금 눌러야 할 키가 잠시 붉게 표시된다. 입력 진도는 그대로, 챌린지 지속, 시간도 계속 흐른다. 비WASD는 무시. 시간 초과만 실패.
- 성공·실패 모두 복귀 시 하강 속도를0으로 초기화하고 0.15초 동안 중력을 정상으로 부드럽게 복원한다. 상승 중 속도는 보존한다.
- 그 시간에 클릭/ArrowUp이 오면 정상 상승을 즉시 적용하고 완화를 종료한다. 입력을 버리는 뜻이 아니다. 추가 무적/시간 정지는 없다.
- 붉은 표시/오류음의 세부 길이는 구현값으로 분리하고 사용자 확정 시간으로 오기하지 않는다.

## 4. 네 가지 실패 페널티
- ink / glitch / crack / fog 각각25%, 지속8초. 시각 방해만, 새 점수·조작·무기 페널티 없음.
- 강한 글리치 불투명 구간0.18초. 8초 타임라인의 시작점0.9/2.1/3.15/4.55/5.7/6.9초, 사이에는 약한 치직임. 플레이어 주변도 동일하게 가린다. 먹물의 기존 플레이 가능 보호는 보존한다.
- 균열/안개는 실제 승인 editor 모양과 아래 값을 그대로 사용한다.
  - crack: variant web, tint steel, opacity0.7, size1.12, count19, width3.7, glow0.5, pulse1.05, x74%, y48%.
  - fog: variant clouds, tint steel, opacity0.9, size210, count12, speed60, spread85.
- 선택 JSON의 activeEffect/sceneTheme은 에디터 상태이지 fog만 적용/심연만 적용이라는 뜻이 아니다.
- 현재 실패효과 위 적 공격 재그리기로 가림이 취소되는 경로도 수정한다. 최종 합성에서도 플레이어/공격이 의도대로 가려져야 한다.
- [승인 설정](../validation/2026-10-30-v01-glitch-preview/selected-settings.json), 같은 폴더 editor.js의 drawEditorCrack/drawEditorFog/editorPalette가 형태 기준.

## 5. 기존·고유 투사체 속도
- 실제 탄 발사 순간마다 base를220~360 px/s에서 뽑고 clamp(base + (현재 실제 스크롤 속도 - 240) × 0.35, 80, 800).
- 예고 시작/공격 객체 생성 때 목표 속도를 넣지 않는다. 각 지연 발사/수정 자탄도 자기 실제 발사 시 샘플링한다. 비행 중에는 유지하여 위치 도약/추적 가속을 막는다.
- scroll240→220~360, 460→297~437, 700→381~521, 770→405.5~545.5.
- 기존 지역별 경로/피격16×11/화면 밖까지 비행 보존.
- [설정](../validation/2026-10-30-v01-projectile-speed/selected-settings.json)의 scroll700/stage/attack/boss2는 시연 입력이다.

## 6. 지역별 고유 공격
- 두 번째 보스부터 기존 walls/signature/global/challenge 외 독립 unique 블록 추가. 기존 공통 공격을 삭제하지 않는다.
- 블록당 무작위1~3세트, 기존 블록 셔플 및 라운드 경계 같은 블록 연속 방지 유지.

## 9. 최종 v3 렌더링 승인
- [최종 시안](../validation/2026-11-02-v01-asset-render-review-v3/preview.html).
- 특수벽/혼합벽 기존 본체·색·재질 유지. 파괴된 높이에서 특수벽 자체 테두리/사선 장식선만 제거. 혼합벽 일반벽·구멍 가장자리, 파괴 원/파편은 유지.
- 초록 성공 판정 안내의 면/경계/깜빡임 모두 그대로. v2의 초록 안내 클립은 폐기. v1 전체 이미지 벽/전역 레이저 교체도 폐기.

- 단일 레이저는 실제 지역별 원본 PNG 재질, 기존 예고·오른쪽→왼쪽 sweep·안전 clip·두께18 유지.
- 전역 레이저는 기존 ray/filament/blur/flare/형태 유지, 지역 테마 laser색만 적용: 수정#c0bcff/산업#ff8a42/신호#dc67ff/중력#a884ff/심연#63e7e2/태양#ff8a35. 백색코어/녹색안전/붉은위험 유지.
- 메타데이터는 v3 asset-analysis.json의 투사체·레이저만 사용. 일부 벽 PNG에는 주변 풍경이 있어 원본 전체/알파 크롭을 일괄 복원하면 안 된다.
- 시안은 full gameplay가 아니다. breakEffect .65초 만료/통과 후/카메라 밖까지 선과 파괴 연출 재등장 여부를 따로 검증한다. 물리적 영구 통로를 새로 만들지 않는다.

## 10. 모바일·입력·출격 대기·버전
- 모바일 가로, 빈 canvas 터치 상승. 오른쪽 아래 가로배치: 발사 왼쪽 / 대시 오른쪽, 각64 CSSpx.
- WASD는 아래 W A S D 한 줄, 각56×56 CSSpx, 간격12px. 챌린지 중 상승/대시/발사는 차단.
- safe-area 적용, 375px 높이·최대8키·멀티터치·중복 상승/합성 click/키 반복 검증. 노치28px는 시연값이지 전 기기 고정값 아님.
- ArrowUp을 클릭과 같은 상승으로 추가. 키 반복/blur 재입력 상태 정리.
- 출격하기 이후 대기는 “출격 준비 중”만. 기존 Escape 취소/음악 준비/10초 fallback/낡은 async 시작 방지 유지. 튜토리얼을 없애는 요청 아님.
- 메인 왼쪽 아래 현재 버전 작게, canonical releases.json 사용. package.json 0.1.0이나 개발 목표0.1 하드코딩 금지.

## 11. 품질 유지 최적화
- HUD 변경 감지와 WASD 노드 재사용, 같은 프레임 적 레이어 재사용만 채택. 레이저 blur 절감안 미채택.
- FHD 최대1920×1080/nativeRAF/논리960×540/배경.5·벽.75·투사체.5·레이저.35 해상도 유지. 기체/보스 화질·효과 삭제 금지.
- [원본5파일 백업](../validation/2026-10-30-v01-performance/original-baseline/README.md) 및 manifest를 덮어쓰지 않는다. 롤백은 성능 변경 부분만, 새 기능 포함 전체 파일 덮어쓰기 금지.
- 헤드리스 측정은 실기기 프레임 보장 아님. 같은 조건/seed/구간의 전후 p50/p95/p99, GPU환경, 실제 렌더버퍼를 기록한다.
- 실패효과 최종 가림은 성능 재사용보다 우선. 플레이어 빔과 적 레이저 공유 버퍼 덮어쓰기 위험을 피한다.

## 12. 보존 규칙 및 범위
- 현재 속도240(+10/진행10점), 상한220점; NOVA/AEGIS460, VELOCITY480부터700. 보스 배율·2초 보간·일시정지 감점 후 속도 유지 그대로.

- 첫 보스20, 이후 새 스테이지 도착 점수+15~20. 보스 HP3/자동충전10초/수동Shift·Ctrl/발사잠금.7초/직선 빔·AEGIS피해3/클리어+10 유지.

- 구현 계획만 생성한다. 실제 배포 요청 전 prepare/new-release, push, 자동배포 실행 없음. 공식 발표·관리 HTML과 보호된 스냅샷은 현재 배포를 유지. 개발 문서는 .memory 초안으로 검증하고 배포 시 공식 생성 파이프라인 사용.
