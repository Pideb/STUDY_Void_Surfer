# Decision: 배포 버전 표기 변경

- 사용자 확정: 다음 게임 배포는0.1, 이후0.11→0.12→0.13.
-0.2나1.0으로의 기준 버전 변경은 사용자 요청 때만 한다. 소수 계산으로 자동 승격하지 않는다.
- 버전을 문자열 기준 버전(`0.1`)과 뒤에 붙는 배포 순번으로 관리한다.0.19 다음은0.110이며0.2로 넘어가지 않는다. 추후 기준 변경을 요청하면 `versionBase`를 명시적으로 변경한다.
- 현재 실제 배포0.01-b와 과거 스냅샷은 유지한다. 지금은 규칙/예고 표기만 수정하며 배포하지 않는다. 문서만 재생성하거나 같은 소스의 준비 명령 재실행으로 새 버전을 만들지 않는 기존 정책은 유지한다.
