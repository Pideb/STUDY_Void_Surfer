# v0.2 배포

- 사용자가 실제 배포·공개 가이드 업데이트를 명시 승인했다. 제공한7개 문구를 그대로 수동 원고에 넣고 v0.2를 크고 굵은 제목으로 표시한다.
- 현재 소스를0.2로 준비하고 전체 검사·빌드·설정·docs:check 이후 커밋/push한다. 실제 Actions 성공·HEAD·운영 번들 SHA256·가이드 본문을 확인한 뒤 record-deployment로 성공을 기록한다. 확인 전 배포 완료를 쓰지 않는다.
- 배포 전 탐색에서 운영 start/finish_play_session과4인자submit_score가 PGRST202로 나왔다. 관리자 연결은 환경에 없다. 적용 가능한 관리 경로를 확인하고, 운영 DB의 필수 gate를 조용히 생략하지 않는다.
- 게임 규칙·판정·소리 변경은 추가하지 않는다. 이번 원고는 사용자 수동 작성으로 취급하며 자동 분석 내역을 섞지 않는다. 보호 과거 스냅샷은 유지한다.
