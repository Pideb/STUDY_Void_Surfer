# v0.1 성능 최적화 전 원본

사용자가 화질 유지 최적화1번을 선택하면서 되돌릴 수 있도록 원래 상태를 기억해 달라고 요청했다. 2026-10-30 실제 파일5개를 경로 구조 그대로 보관한다. `manifest.json`에 HEAD/바이트수/SHA256/수치를 기록하며, `preserve-baseline.mjs`는 기존 내용이 다른 백업을 덮어쓰지 않는다.

- 전체 렌더 최대1920×1080, native RAF. 현재 해상도 정책 유지.
- 레이어 배율: 배경0.5, 벽0.75, 투사체0.5, 레이저0.35.
- 적 레이저 blur5겹의 기존 값과 광선 수 유지. 넓은 빔 필라멘트11/좁은 빔5 등 전체 원본은 laser-renderer.js에 보존.
- HUD는 기존 동일값도 반복 갱신/WASD 목록 재생성 동작을 포함해 보존.
- 실패 효과 위에 적 공격을 재표시할 때 원본은 다시 그린다. 캐시 없이 동작하는 기준으로 보존.

후속 계획에서는 성능 변경을 기능 변경과 구분해 기록/커밋하고 되돌림 가능성을 검증한다. 새 v0.1 기능이 추가된 뒤 이 파일 전체를 덮어씌우면 다른 기능까지 과거로 돌아갈 수 있으므로, 성능 변경 부분만 비교·되돌리는 기준 자료로 사용한다. 이 폴더는 실행되는 게임 자산이나 배포 버전이 아니다.
