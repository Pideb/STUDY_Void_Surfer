# 플레이 검토용 인계

19개 Task를 구현·검증·커밋했습니다. **push·배포하지 않았습니다.** 운영은0.01-b(표시v0.1b)이며 다음 배포 기준만0.2입니다.

## 지금 확인

```powershell
npm run dev
```

터미널에 표시되는 로컬 주소에서 플레이하세요. 모든 기체가 임시 해금되어 있습니다. 첫 보스는 일반벽20개 통과 후 저속, 두 번째는 새 지역 일반벽15개 후 고속, 세 번째는 변속입니다. 보스 벽과 전환 추가벽은 카운트에서 제외합니다.

- [플레이어 가이드](../../../public/guide/index.html): 게임 메뉴에서도 새 탭으로 열립니다. 플레이어 업데이트 원고는 아직 비어 있습니다.
- [관리 검토본](draft-docs/docs/management/void-surfer-management.html): 현재 수치·슬라이더·업데이트 초안·개발 예시12개.
- [발표 검토본](draft-docs/docs/releases/void-surfer-latest.html): 미배포 상태를 표시한 변경 자료.
- [검증 보고서](report.md): 전체1,347테스트,432개 유한 회피 경로, 브라우저·성능·DB 검사와 한계.

모바일은 가로로 플레이하며 세로 전환 후 가로로 돌아오면 계속하기를 눌러 재개합니다. 결과창은 바깥 클릭/새 키로 재시작, ESC로 메인메뉴입니다. 실제 PC GPU와 휴대폰에서 프레임·터치감을 확인해 주세요.

## 배포 전 남은 운영 작업

1. [DB 운영 절차](../../../docs/operations/play-records.md)에 따라 새 migration2개를 순서대로 적용합니다. 운영에서는 아직 실행하지 않았습니다.
2. 실제 Microsoft 로그인, 계정 최고기록, 비공개 통계 쓰기, 동점 정렬 및 독립 연결 동시 제출을 확인합니다. 일반 사용자에게 플레이시간·횟수가 노출되면 안 됩니다.
3. 사용자 플레이 피드백을 반영합니다. 수동 플레이어 업데이트는 `docs/player/updates.json`에 직접 작성하고 `npm run guide:build`를 실행합니다.
4. **실제 배포 요청 후에만** `npm run release:prepare -- --new-release --title "실제 변경 요약" --change "확인된 변경"`를 실행합니다. 전체검증·공식문서·docs:check 후 커밋/push합니다.
5. Actions 성공·배포 HEAD·운영 번들 SHA256을 직접 확인한 증거로 `release:record-deployment`를 실행하고 기록을 다시 커밋합니다. 공개 주소만으로 성공을 기록하지 않습니다.

현재 `npm run docs:check`는 게임 지문이 운영 문서와 달라 종료1입니다. 배포 전 차단이 정상이며 우회하거나 운영 지문을 수동으로 바꾸지 않았습니다. 확정된 공식 HTML·과거 스냅샷은 보존했습니다. 검토본은 `.memory` 안에만 있습니다.
