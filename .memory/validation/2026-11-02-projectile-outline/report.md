## 검증

- 실제 게임 renderer와 지역 PNG를 사용해6지역×PC/모바일×변경 전후 **24캡처**를 만들었습니다. [전후 비교 열기](review.html).
- 일반/부모탄12사례 모두 원래 투명했던 위치에 해당 테마색의 밝은 외곽 픽셀이 추가됨을 확인했습니다. 반환 방향도 캡처에 포함했습니다. [브라우저 결과](render-check.json).
- 실루엣은 최초 표시 때 작은2배 raster canvas로 만들며, 원본 전체 해상도의 픽셀을 분석하지 않습니다. 이미지·crop·크기·팔레트별 WeakMap 캐시를 사용합니다. 예열 후6,000회 그리기에서 픽셀 읽기0회였습니다. 매 프레임 blur/filter 처리를 추가하지 않았습니다.
- 렌더·레이어·투사체·고유 공격 관련5파일158테스트와 문서3파일20테스트 통과. build·verify:config 통과.
- Headless Edge에서FHD1920×1080과모바일844×390을 확인했습니다. 실제 휴대폰 하드웨어 FPS를 보장하는 검사는 아닙니다.
- 원본 이미지·점수·음악·운영 버전·DB·보호 스냅샷은 유지했습니다. 새 비교 링크만 개발 카탈로그에 추가했고 public 빌드에는 개발 시안을 포함하지 않습니다. push·배포 없음.
